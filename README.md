# GayaKu

GayaKu is a virtual earring try-on web app that helps users preview how different earring styles look on their face in real time.

The app uses live camera input and face landmark detection to:

- overlay earrings on the user while they move
- analyze face shape for personalized style suggestions
- let users take and download snapshots of them with the earrings

## Getting Started

Run the development server:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
